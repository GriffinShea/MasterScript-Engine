See https://griffinshea.github.io/MasterScript.html for information about the project, documentation, and tutorials.

Install Python and dependencies listed below and run "py src/main.py" to play.

Tested using:
	Python 3.14.3
	Windows 10

With packages:
	attrs==25.4.0
	pygame-ce==2.5.7
	pyglm==2.8.3
	PyOpenGL==3.1.10
	PyOpenGL-accelerate==3.1.10

To install dependencies:
	pip install attrs
	pip install pygame-ce
	pip install pyglm
	pip install pyopengl pyopengl_accelerate
